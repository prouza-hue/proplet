# Proplet UI rules

## Readability is a product requirement

- Text that explains rules, consequences, consent, warnings, or the next action is never fine print.
- This meaningful copy must be at least 14 CSS px on desktop and 15 CSS px at widths up to 600 px, with line-height of at least 1.35.
- Sizes below 12 CSS px are reserved for genuinely optional metadata or decoration, never information needed to understand the game.
- Every new responsive component must be checked at 390 CSS px as well as at a normal laptop width. Narrowing a desktop window is not enough unless the text remains comfortably readable there.
- When space is tight, shorten or reflow the copy; do not solve the problem by shrinking meaningful text.
