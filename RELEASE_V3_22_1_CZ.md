# Proplet v3.22.1 — Dark Found-Path Legibility Hotfix

Malý vizuální hotfix k Night Mode z v3.22.

## Změna

Nalezené buňky v dark mode nyní používají:

- 70 % barvy příslušného slova + 30 % tmavého povrchu,
- velmi tmavé písmo `#0c0b10`,
- jemný světlý mikro-stín pouze pro ostrost hran znaku.

Výsledkem je výrazně rychlejší čtení již nalezených slov bez návratu k jasným pastelovým plochám light mode.

## Beze změny

- light mode,
- dark-mode základ a ostatní obrazovky,
- starter a jeho XP,
- Fold/rotation responsivita,
- Daily, Free, Rescue a legacy puzzle,
- SQL a databázové schéma.
