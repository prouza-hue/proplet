# Frozen recognition data

`wordfreq-cs-runtime.txt` is a normalized Czech alphabetic subset of wordfreq 3.1.1 data by Robyn Speer, selected using the existing Proplet runtime frequency thresholds. It is recognition-only data, not a list of approved puzzle answers. No frequencies or dictionary definitions are included.

Source: https://github.com/rspeer/wordfreq . Source attribution and bibliography: https://github.com/rspeer/wordfreq/blob/master/NOTICE.md . Underlying sources credited by wordfreq include Google Books Ngrams, University of Leeds Centre for Translation Studies, Wikipedia contributors, ParaCrawl, OPUS/OpenSubtitles 2018 and OpenSubtitles, and freely available SUBTLEX data by Marc Brysbaert and collaborators.

The wordfreq code is Apache-2.0; no code from the package is embedded in this data file. See wordfreq-manifest.json for exact version, thresholds, cardinality, and SHA-256. Public preview attribution is also in preview/gen6/data-sources.html.
