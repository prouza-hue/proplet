# Veřejný podporovatel — detail avataru ve výsledcích

1. 11. 2026. Pracovní větev `codex/patron-avatar-info` vychází z ověřeného produkčního main `f7f10bb` (v4.10.3). UI zachovává Tiskařskou dílnu a používá stávající nativní `patronDialog`, jehož detail osoby je kompaktní. Ukazuje jméno, přesnou vykreslenou podobu kliknutého avataru a značku Podporovatel. Jediný odstavec vysvětluje provoz a rozvoj hry a možnost získat vlastní značku. CTA Podpořit Proplet přepíná ve stejném dialogu na existující nabídku podpory. Neoznamuje žádnou částku ani potvrzený bankovní převod.

Pouze veřejně označený avatar v řádcích herních výsledků se mění na skutečné tlačítko s přístupným názvem a `aria-haspopup=dialog`. Soukromé a nepodporovatelské avatary zůstávají statické. Opakované dekorování zachovává tentýž uzel tlačítka a hydratovaný obrázek; detail klonuje skutečně vykreslené děti avataru, aby se nezměnil na avatar návštěvníka. Vlastní řádek používá jméno z profilu, nikoli Ty. Zavření detailu nebo následné nabídky vrací fokus na původní avatar. Vypnutí veřejné značky či funkce obnoví statický avatar a nemění herní data.

Existující aktivní `test_patron_client.cjs` nyní ověřuje podporovaný/nepodporovaný/soukromý avatar, skutečné vykreslené podklady, opakované dekorování, jméno vlastníka, přechod do nabídky, návrat fokusu, absenci nového serverového zápisu a live OFF. Izolovaný Studio náhled `?patronInfo=1` ukazuje stejnou skutečnou výsledkovou komponentu se syntetickými řádky a blokovanými patroními zápisy. Root provádí vizuální kontrolu. Backendový agent koordinuje úzkou nepeněžní značku vlastníka s auditem; UI nefalšuje příspěvek ani finanční historii.

Koordinovaná verze v4.10.4 používá cache `proplet-v4.10.4-patron-avatar1`, core token `41004patron-avatar1`, runtime `41004` a token změněných patroních JS/CSS `patron-avatar1`. Měsíční skóre, ostatní assety, platby a jejich současná cesta zůstávají zachované. Tento záznam sám nepotvrzuje produkční nasazení.
