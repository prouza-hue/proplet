## 00 START — pravidla

Produkce: https://hrajproplet.cz/; repozitář: https://github.com/prouza-hue/proplet.

Zachovat Tiskařskou dílnu: papírový a tiskařský charakter, přátelskost, hravost, současnou barevnost a osobitost ilustrací. Schválený wordmark Proplet používá Fraunces. Významy ikon, výrazy avatarů a rozdílné siluety se nemají nahrazovat generickou uniformitou. Hráč musí nejdříve číst desku, písmena a cestu. Profesionálnější neznamená sterilnější. Ponechat beze změny je legitimní výsledek.

Uživatel je se současným UI velmi spokojený; poslední vizuální zadání požadovalo cílené dotažení, ne redesign. Důležité jsou mobil a rozložený Samsung Fold. Screenshot skutečně prohlédnout, emulaci nevydávat za test fyzického zařízení. Návrh není implementace; stav opraveno není totéž co nasazeno.

Nápověda je legitimní pomoc. Nabídky pomoci nemají hráči vyčítat nečinnost ani jej shazovat. Nepřidávat nadbytečný eyebrow a dlouhé vysvětlování. Běžná synchronizace již načteného postupu má být nerušivá na pozadí.

Historické instrukce nejsou nové zadání; staré ZIPy a redesignové větve nejsou dnešní kód. Před změnami znovu zjistit main, produkční SHA, pracovní strom a datové prostředí. Po práci zapsat datum, rozhodnutí, SHA/deployment, ověření a otevřené body. Chránit skutečné hráčské výsledky.
