# Pestrá hra: UI preview v3, 2. října 2026

Tato iterace je určena ke schválení vzhledu a herního chování. Nenahrává nic na main ani do Supabase. Stejná adresa preview nyní ukazuje zamýšlený běžný průchod aplikací; přihlášení a synchronizace zůstávají izolované.

- Dnes: menší zavíratelná pozvánka „300 nových Propletů“, odkaz Vybrat hru. Zavření se pamatuje v tomto prohlížeči.
- Hrát: šest kompaktních karet; vedle tlačítka je další úroveň nebo rozehraná deska. Žádné přepínače pořadí ani duplicitní banner. U prvních tří obtížností je drobný počet zbývajících nových desek.

- Přehled postupu: původní výsledky a rozbalovací katalog všech úrovní podle původních čísel. Kontrolní katalogy preview jsou pouze pod ?review=1.
- Mozkomor i Mozkokalypsa ponechávají schválené pořadí. Možnost budoucí další série zůstává v manifestu, bez dnešního ovládání.
