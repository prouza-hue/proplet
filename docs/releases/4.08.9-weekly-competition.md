# 4.08.9 — weekly competition

Approved competition design promoted from the isolated review into the game. The Dnes competition entry now says “Hraj s týmem o zlatou trofej” as requested in the screenshot. ## Data and safety

The new screen lazily reads existing `/api/rankings/xp?period=week` and, for authenticated players, `/api/team-victories`. No new writes, awards, migrations, observers or polling. Account snapshots and generation guards discard late responses after an account/team switch. Guest, no-team, private-team, unavailable and empty states are explicit. No fabricated rankings or wins ship in the module. Existing victory acknowledgement/award behavior is unchanged.

All changed cached scripts have new query versions. Shell and runtime version are 4.08.9; previous archive-layout2 / result-heading2 fixes remain. Production build still removes the fixture adapter. Release is based on production commit 29760aaed27f22fb07c0d2fe122a404eba239f6e, not the model-data review branch.
