# Proplet v3.22.2

Aktuální release: **v3.22.2 — Dark Found-Row Legibility Hotfix**.

Mikro-hotfix nad v3.22.1. V tmavém režimu mají tmavé písmo nejen nalezené stopy v desce, ale nově i barevné štítky v řádku **Nalezeno**. Light mode, starter, Fold responsivita i puzzle obsah zůstávají beze změny.

Pro update z v3.22.1 použij `proplet-v3.22.2-update.zip`. Žádná SQL migrace není potřeba.
