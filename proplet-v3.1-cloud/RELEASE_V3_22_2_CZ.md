# Proplet v3.22.2 — Dark Found-Row Legibility Hotfix

Mikro-hotfix nad v3.22.1.

## Změna

Barevné štítky nalezených slov v řádku **Nalezeno** v dark mode nyní používají:

- 70 % barvy příslušného slova + 30 % tmavého povrchu,
- velmi tmavé písmo `#0c0b10`,
- jemný mikro-stín pro ostrost znaku.

Tím se vizuálně i kontrastně sjednocují s nalezenými stopami přímo v herní desce.

## Beze změny

- light mode,
- ostatní dark-mode plochy,
- starter a game feel,
- Fold/rotation responsivita,
- Daily, Free, Rescue a legacy puzzle,
- SQL a databázové schéma.
