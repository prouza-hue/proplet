# Proplet v3.6 — Copy & Polish

Čistě textový a UX release. Herní logika, puzzle banka i backendové API zůstávají beze změny.

## Hlavní změny

- sjednocená česká terminologie: Denní výzva, série, čisté řešení, hodnost, pořadí, vibrace
- herní úloha = úroveň; XP postup = hodnost
- přepracovaný onboarding s jasnější formulací unikátní cesty
- tutorial PES vede přes roh, ne rovně
- výraznější vlastní hlas Propletu v hláškách a výsledkovce
- systémové české skloňování: tah/tahy/tahů, den/dny/dní, slovo/slova/slov, nápověda/nápovědy/nápověd atd.
- autorská patička na neherních obrazovkách

## Beze změny

- 795 puzzle
- strict unique-route pravidlo
- Daily / Free / rescue logika
- XP ekonomika
- databáze a Supabase schéma
