# Proplet v3.7 — Playtest

Release vznikl z prvního skutečného rodinného playtestu.

## Hráčský polish

- první tutorial už nejde přeskočit
- PES v tutorialu vede přes roh
- při luštění je vidět číslo úrovně: např. `Mozkožrout 5`
- panel slov je rozdělen na `Zbývá` a `Nalezeno`
- těžší banka preferuje delší slova

## Soutěžení

- žebříček každé konkrétní úrovně
- sdílení výsledku včetně umístění v lize
- historie odehraných úrovní
- možnost z detailu úroveň znovu zahrát a zlepšit výsledek

## Ligy a účty

- seznam existujících chráněných lig
- založení nové ligy s PINem
- starší ligu lze dál zadat ručně kódem
- kód ligy se normalizuje bez ohledu na velikost písmen
- tlačítko `Zobrazit heslo`

## Denní připomínka

Volitelný Web Push připomene novou Denní výzvu. Push se váže na konkrétní zařízení a neposílá se hráčům, kteří už daný den Daily dokončili.
