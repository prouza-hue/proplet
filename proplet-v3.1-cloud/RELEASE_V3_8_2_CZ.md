# Proplet v3.8.2 — Push nudge + čistší PIN ligy

## Připomínky Denní výzvy

Po dokončení Denní výzvy se přihlášenému hráči, který ještě nemá push zapnutý, aktivně nabídne denní připomínka.

Pokud zvolí **Teď ne**:

1. první odmítnutí → nabídka znovu nejdřív následující den,
2. druhé odmítnutí → nabídka znovu nejdřív za 7 dní,
3. třetí odmítnutí → automatická nabídka končí.

Ruční zapnutí zůstává vždy v **Já → Nový Proplet na mobil**.

Pokud hráč push zapne nebo jej později ručně vypne, automatický nudge už se nevnucuje.

## PIN rodinné ligy

PIN má od v3.8.2 jedinou jasnou roli: **sdílené pozvání pro vytvoření nového hráče v existující rodinné lize**.

- nový člen rodiny zadá PIN jednou při vytváření svého hráče,
- existující hráč se na dalších zařízeních přihlašuje svým vlastním heslem — PIN nepotřebuje,
- nastavení veřejné **Ligy rodin** může změnit kterýkoli přihlášený člen rodiny bez PINu,
- rodinný PIN zůstává uložený a chrání vstup nových členů.

V rodině tedy nejsou žádní administrátoři; všichni přihlášení členové mají stejná práva.
